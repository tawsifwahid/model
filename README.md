# 3D Classroom Viewer

## চালানোর নিয়ম
ZIP এক্সট্র্যাক্ট করুন। সব ফাইল একই জায়গায় রাখুন এবং `index.html` ব্রাউজারে খুলুন। তিন.js ও প্রয়োজনীয় সহায়ক লাইব্রেরি সঙ্গে দেওয়া আছে; চালানোর জন্য ইন্টারনেট প্রয়োজন নেই। WebGL সমর্থিত আধুনিক ব্রাউজার লাগবে। ব্রাউজার সরাসরি ফাইল খুলতে বাধা দিলে একই ডিরেক্টরিতে স্ট্যাটিক সার্ভার চালান, যেমন `python -m http.server 8000`।

## গঠন ও আপডেট
- HTML: `index.html`; স্টাইল: `viewer.css`।
- প্রতিটি মডেলের আলাদা JS আছে, যেমন `desk.js`, `chair.js`, `classroom.js`। বিদ্যমান কোনো মডেলের কাজ তার নিজস্ব ফাইলে পরিবর্তন করলে, তার নিবন্ধন-আইডি ও প্রয়োজনীয় ইন্টারফেস অপরিবর্তিত রাখলে অন্য ফাইল বদলাতে হয় না। ক্লাসরুমে ব্যবহৃত মডেল বদলালে ক্লাসরুমেও পরিবর্তন দেখা যাবে।
- শেয়ার করা উপাদান: `builders.js`, `materials.js`, `registry.js`, `optimize.js`; ভিউয়ারের আচরণ `viewer.js`, `ui.js`, `lighting.js`, `postfx.js` ইত্যাদিতে। শেয়ার করা ইন্টারফেস ভেঙে বদলালে নির্ভরশীল ফাইল সংশোধনের প্রয়োজন হতে পারে।
- নতুন মডেল যোগ করতে নতুন JS ফাইল একই জায়গায় রেখে `manifest.js`-এর `props` তালিকায় নাম যোগ করতে হবে। বিদ্যমান ফাইল আপডেটে এটি দরকার হয় না।
- তিন.js r128 এবং তার সহায়ক ফাইলগুলো লোকাল রাখা হয়েছে। লাইসেন্স `THREE-LICENSE.txt`-এ। React বা TypeScript নেই।

## কন্ট্রোল
এক আঙুল/মাউস ড্র্যাগে ঘোরান; দুই আঙুল/স্ক্রল দিয়ে জুম করুন। নিচে মডেল নির্বাচন; ডানে Spin, FX, Walls (শুধু ক্লাসরুম), Quality, Reset, Save এবং সূর্যের উচ্চতার স্লাইডার।
